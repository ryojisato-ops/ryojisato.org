# ryojisato.org

佐藤亮司の研究者個人サイトです。依存関係のない静的HTML/CSS/JavaScriptで構成し、GitHub Pagesで公開します。

## 構成

- `/` — ホーム
- `/about/` — プロフィール
- `/research/` — 研究
- `/publications/` — 主な業績
- `/books/` — 著書
- `/books/free-energy-principle/` — 『自由エネルギー原理を哲学する』Web付録

公開ファイルは `dist/` にあります。GitHub Actionsが `main` ブランチへの更新を自動でGitHub Pagesへ反映します。
